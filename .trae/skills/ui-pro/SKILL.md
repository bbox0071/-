# UI Pro

## 功能概述

这个Skill专注于美化前端页面的UI设计，包括但不限于以下功能：

### 样式优化
- 调整颜色方案和主题
- 优化字体和排版
- 添加渐变和阴影效果
- 改进按钮和表单样式

### 组件美化
- 卡片样式优化
- 列表和表格美化
- 导航栏样式调整
- 模态框和弹窗美化

### 响应式布局
- 移动端适配优化
- 断点调整
- 弹性布局优化

### 交互效果
- 添加动画和过渡效果
- 悬停状态美化
- 加载状态优化

## 使用场景

当用户提出以下需求时，应该触发此Skill：
- "美化页面"
- "更改UI"
- "优化样式"
- "调整布局"
- "改进视觉效果"
- "添加动画"
- "响应式适配"

## 最佳实践

1. **分析现有代码**：先查看项目的CSS文件和组件结构
2. **制定优化方案**：根据用户需求制定具体的改进计划
3. **逐步实施**：分步骤进行UI改进，确保每一步都可验证
4. **测试验证**：在不同设备和浏览器上测试效果

## 示例

用户："帮我美化任务卡片的样式"

执行步骤：
1. 查看现有的TaskCard组件样式
2. 设计新的卡片样式（圆角、阴影、边框）
3. 实现样式改进
4. 验证效果
